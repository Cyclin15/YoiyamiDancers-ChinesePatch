# 宵暗舞者（Yoiyami Dancers）简体中文汉化包

适用于 Steam 版《宵暗舞者（Yoiyami Dancers）》**ver 1.4.2** 的非官方简体中文汉化包。

东方Project 同人节奏游戏。本汉化包覆盖游戏的文本、字体资源，解压即用。

## 下载

前往 [Releases](../../releases) 页面下载 `YoiyamiDancers_汉化包_v1.4.2.zip`。

## 安装方法

1. 下载并解压汉化包；
2. 将解压出的 `asset` 文件夹整个复制到游戏根目录（即 `YoiyamiDancers.exe` 所在目录），选择覆盖；
3. 启动游戏即为中文版。

## 卸载方法

用汉化包内 `原版备份` 文件夹中的三个 `.dxa` 文件覆盖回 `asset` 目录即可还原为日文原版。
